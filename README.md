# 밤사이

국내 시장이 닫힌 밤과 주말에도 거래되는 **하이퍼리퀴드 한국 주식 perp** 가격으로
**① 다음 날 장 시작 가격이 오를지 내릴지**, **② 지금 두 시장 사이 시세차익 기회가 있는지** 알려주는 서비스

- 웹앱: `배포 후 추가`
- API 문서: `/api/openapi.json` · MCP: `/api/mcp` · 화면 안내: `/developers`
- 제출용 1~2장 요약 PRD: [docs/prd-submission.md](docs/prd-submission.md)

# PRD

## 한 줄 요약

국내 시장이 닫혀 있는 65%의 시간(넥스트레이드 포함) 동안에도 삼성전자·SK하이닉스·현대차 가격은 해외 24시간 시장에서 움직임.
이 가격을 원화로 바꿔 **다음 장 시작 가격의 방향과 범위**를 확률로 보여주고, 장중에는 **비용 뺀 시세차익 기회**를 계산해 주문 버튼(출시 예정)까지 연결.

## 1. 해결하려는 문제

| # | 누가 | 문제 | 지금은 어떻게 하나 |
|---|---|---|---|
| P1 | 삼성전자·하이닉스 보유 개인 | **"내일 아침 오를까, 내릴까?"에 답할 근거가 없음.** 미국장 끝난 뒤, 주말·연휴 동안 생긴 뉴스가 다음 날 장 시작 가격에 얼마나 반영될지 모름 | 미국 지수, ADR, 커뮤니티 분위기로 짐작 |
| P2 | 주식·코인 같이 하는 트레이더 | **두 시장 차이를 보려면 창 3개(하이퍼리퀴드, HTS, 업비트 환율)를 띄우고 직접 계산.** 수수료·세금·환전·펀딩비를 빼면 실제로 남는지 알 수 없음 | 엑셀, 감으로 판단 |
| P3 | 자동매매·AI 에이전트 사용자 | 두 시장 시세·가격 차이·예측을 **한 번에 조회하는 API가 없음** | 거래소별 API 따로 붙여서 직접 구현 |

**문제의 크기 (2026-11-05 직접 조회)**

- 국내 시장은 넥스트레이드(08:00–08:50, 15:30–20:00)를 포함해도 하루 11시간 50분, 주 약 59시간(168시간의 35%). 정규장만 보면 주 32.5시간(19%)
- 하이퍼리퀴드 `xyz:SKHX`(SK하이닉스) 24시간 거래대금 **약 5.4억 달러**, `xyz:SMSN`(삼성전자) 약 0.9억 달러
- 하이퍼리퀴드 상장(2026-02-20 한국 시간 새벽) 이후 국내 시장 개장 174번 중 **39번이 주말·연휴 뒤 개장**

## 2. 타겟 고객

| 구분 | 고객 | 이 고객을 고른 이유 | 주로 쓰는 화면 |
|---|---|---|---|
| **핵심(Beachhead)** | 삼성전자·SK하이닉스를 **보유한 30~40대 직장인 투자자** | 개인 보유자가 많은 대표 종목이고 perp 거래대금도 가장 큼. 아침 8시 국내 시장이 열리기 전(출근 준비·출근길)에 판단할 일이 매일 있음 | 홈 |
| 확장 1 | 업비트·하이퍼리퀴드를 같이 쓰는 **주식·코인 겸업 트레이더** | 이미 perp를 알고 있어서 설명 비용이 낮고, 차익·갭 매매로 주문 전환 가능성이 큼 | 종목 상세 |
| 확장 2 | 에이전트·자동매매를 직접 만드는 **빌더** | 과제 배경과 같은 흐름. API 하나로 쓰는 유입 채널 | API · MCP |

**하지 않는 것**: 해외 perp 거래 권유. 국내 투자자 보호 대상이 아니라서 홈은 '조회와 판단'까지만 제공함 (금융위·금감원 2026-10-16 유의사항 발표)

## 3. 가설

가장 위험한 가정부터 순서대로 검증.

| # | 가설 | 위험도 | 이 가설이 틀리면 |
|---|---|---|---|
| **H1 신호** | 국내 시장이 모두 닫힌 동안(20:00~08:00) 하이퍼리퀴드에서 충분히 거래됐다면, 그 가격이 움직인 방향대로 **다음 날 08:00 국내 시장도 80% 이상 같은 방향으로 시작**한다 | 가장 높음 | 서비스 존재 이유가 없음 |
| **H2 가치** | 보유 종목의 "오를 확률"을 보여주면 **장 시작 전에 다시 찾아온다** | 높음 | 신기한 숫자로 끝나고 습관이 안 됨 |
| **H3 신뢰** | 지난 예측 기록을 같이 보여줘야 **확률을 믿고 행동한다** | 중간 | 숫자만 보고 떠나거나, 반대로 맹신 |
| **H4 전환** | 수수료·세금까지 뺀 **시세차익 기회**를 보여주면 조회가 **주문 버튼 클릭**으로 이어진다 (주문은 출시 전이라 클릭 시 출시 알림 신청) | 중간 | 종목 상세가 구경용에 그침 |
| **H5 에이전트** | 조회 API·MCP를 열면 **화면 밖 호출(에이전트)** 이 생긴다 | 낮음 | 개발자 채널을 접고 앱에 집중 |

**H1은 출시 전 과거 데이터로 먼저 검증**

**왜 이 기준인가**
- 개인 투자자는 정규장(09:00–15:30)뿐 아니라 넥스트레이드(08:00–08:50, 15:30–20:00)에서도 거래함 → '국내 시장'은 둘을 합친 08:00–20:00
- 국내가 정말 닫힌 시간은 **20:00 → 다음 거래일 08:00**(평일 12시간, 주말·연휴는 더 김). 이때 움직이는 건 하이퍼리퀴드뿐
- 그래서 **기준 = 20:00 국내 마지막 가격**, **맞힐 대상 = 08:00 국내 시장이 다시 열렸을 때 개인이 거래할 수 있는 가격**
- 08:00 첫 체결 한 건은 거래가 적어 들쭉날쭉함 → **08:00~08:10 거래량 가중 평균**을 씀 (아래 비교표에서 5분·10분 평균이 가장 안정적)

**채점 방법**
- 하이퍼리퀴드 움직임 = 08:00 하이퍼리퀴드 가격(원화 환산) ÷ 전날 20:00 국내 가격 − 1
- 국내 움직임 = 08:00~08:10 평균 가격 ÷ 전날 20:00 국내 가격 − 1
- 둘의 방향(+/−)이 같으면 '따라감'. 둘 중 하나라도 ±0.05% 안쪽이면 '거의 그대로'로 따로 표시하고 비율에서 뺌
- **조건: 그날 밤(20:00~08:00) 하이퍼리퀴드 거래대금 100만 달러 이상.** 거래가 적으면 몇 건의 주문으로도 가격이 흔들려 '시장의 판단'으로 보기 어려움 (아래 근거)

| 종목 | **방향대로 (거래 충분한 밤)** | 전체 밤 | 80% 구간 실제 포함 | 예상 가격 오차 | 비교: 어제 20:00 가격 그대로 |
|---|---|---|---|---|---|
| 삼성전자 | **88.2%** (119번 중 105번) | 85.8% (134번 중 115번) | 83.2% | 1.22%p | 2.40%p |
| SK하이닉스 | **85.4%** (130번 중 111번) | 85.4% (137번 중 117번) | 89.1% | 1.10%p | 2.84%p |
| 현대차 | **판단 보류** (7번 중 5번) | 66.7% (135번 중 90번) | 88.2% | 1.26%p | 1.53%p |

**거래대금 조건의 근거** (같은 기간, 세 종목 합산)

| 밤사이 하이퍼리퀴드 거래대금 | 해당 밤 | 방향대로 열림 |
|---|---|---|
| 100만 달러 미만 | 150 | 67.3% |
| 100만 달러 이상 | 256 | **86.3%** |
| (참고) 50만 / 200만 달러 이상 | 290 / 232 | 84.8% / 87.1% |

- 한 종목 안에서도 거래가 많은 밤이 더 잘 맞음: 삼성전자 78.8% → 92.6%, SK하이닉스 81.2% → 89.7% (각자 중간값 아래/위)
- 현대차는 밤사이 거래대금 중간값이 23만 달러(삼성전자 1,760만, SK하이닉스 9,700만)라 거의 모든 밤이 기준 미만
- 기준선은 결과를 보고 정함. 50만~200만 달러 어디에 그어도 85~87%라 숫자 하나에 좌우되지는 않지만, 앞으로 쌓이는 밤으로 다시 확인해야 함
- 화면: 그날 밤 거래가 기준 미만으로 보이면(지금까지 밤 거래와 최근 20일 밤 거래의 중간값 중 큰 쪽) 예측 옆에 '거래 적어 덜 정확' 표시

어느 시점 가격으로 채점할지 비교 (조건 없이 전체 밤, 하이퍼리퀴드 방향대로 열린 비율)

| 종목 | 08:00 첫 체결 | 08:00~08:05 평균 | **08:00~08:10 평균** | 08:00~08:30 평균 | 정규장 09:00 |
|---|---|---|---|---|---|
| 삼성전자 | 80.5% | 85.3% | **85.8%** | 84.6% | 83.5% |
| SK하이닉스 | 85.9% | 85.4% | **85.4%** | 84.2% | 84.1% |
| 현대차 | 70.1% | 66.9% | **66.7%** | 69.9% | 73.3% |

- 기간: **2026-04-13 ~ 2026-11-05, 종목별 139번.** 80% 구간·오차는 앞 20번을 학습에만 쓰고 나머지 119번으로 채점. 하이퍼리퀴드 상장은 2026-02-20(한국 시간 새벽 5시, SK하이닉스 기준)이지만, API가 1시간봉을 최근 5,000개(약 7개월)만 보관해서 08:00 가격이 있는 4월 13일부터 채점 가능. 시간이 지나면 표본이 계속 늘어남
- 이전 기준(정규장 15:30 종가 → 09:00 시가)에서는 91.2 / 90.8 / 85.5%였음. 15:30~20:00 넥스트레이드에서 이미 보이는 움직임까지 '예측'으로 쳤기 때문에 높게 나온 것 → 서비스 전제와 맞지 않아 기준을 바꿈
- 결론: **삼성전자·SK하이닉스 통과, 현대차 판단 보류.** 현대차는 하이퍼리퀴드 거래가 너무 적어 기준을 넘는 밤이 거의 없음 → 예측에 '거래 적어 덜 정확' 표시
- 화면에서도 같은 숫자를 매일 다시 계산해 공개 (H3 검증 장치)

### 예측 계산법

화면의 '오를 확률·예상 가격·예상 범위(80% 구간)'는 아래 순서로 계산함. 사용자용 설명은 소개 페이지('밤사이는 이렇게 계산해요')에 있음. 모델은 일부러 단순하게 둠 (표본이 종목별 140번 남짓이라 복잡하면 과적합되고, 초보도 이해할 수 있어야 해서)

1. **밤사이 차이** `g` = 지금 하이퍼리퀴드 가격(원화) ÷ 어제 20:00 국내 가격 − 1
2. **예상 움직임** `μ` = α + β × g
   - β = 과거 개장에서 국내가 하이퍼리퀴드 움직임을 평균 몇 배 따라갔는지. 1(그대로 따라감) 쪽으로 당겨서 급락일 몇 번에 흔들리지 않게 함
   - α = 하이퍼리퀴드와 상관없이 생기는 평균 차이 (거의 0)
3. **불확실성** `σ` = √(과거 예측이 빗나간 폭² + β² × 하이퍼리퀴드 시간당 변동성² × 장 열리기까지 남은 시간)
   - 빗나간 폭은 평일 밤 / 주말·연휴를 따로 계산 (주말이 더 큼)
   - 남은 시간이 길수록 하이퍼리퀴드가 더 움직일 수 있으니 범위를 넓힘
4. **결과**
   - 예상 가격 = 어제 20:00 가격 × (1 + μ)
   - 오를 확률 = 정규분포에서 0보다 클 확률 Φ(μ / σ)
   - 예상 범위(80% 구간) = μ ± 1.28σ. 10번 중 8번은 이 안에서 시작하도록 잡은 범위
5. **검증**: 그날 이전 데이터로만 2~4를 계산해 그날 결과와 비교 (walk-forward). 미래 정보가 섞이지 않음

**예시: SK하이닉스, 2026-11-04 아침** (실제 채점과 같은 방식: 11월 3일까지 137번 개장으로 맞춘 계수 α −0.22%, β 0.875, 평일 밤 σ 1.36%)

| 단계 | 값 |
|---|---|
| 어제(11/3) 20:00 국내 가격 | 1,414,000원 |
| 11/4 08:00 하이퍼리퀴드 가격 (원화) | 1,461,621원 → `g` = **+3.37%** |
| 예상 움직임 `μ` = −0.22% + 0.875 × 3.37% | **+2.73%** → 예상 가격 약 **1,452,600원** |
| 불확실성 `σ` (08:00이라 남은 시간 0) | 1.36% |
| 오를 확률 Φ(2.73 / 1.36) | **약 98%** (97.8%) |
| 예상 범위 2.73% ± 1.74% | +0.99% ~ +4.47% → 약 1,428,000원 ~ 1,477,200원 |
| **실제** 08:00~08:10 평균 | **1,451,776원 (+2.67%)** → 방향 맞음, 예상 범위 안 |

- 지금(11/5) 기준 계수는 α −0.24%, β 0.88, σ 1.37%로 매일 조금씩 바뀜. 예시는 그날 아침 실제로 썼을 계수로 계산함 (서버 채점 값 +2.7289%와 일치)

## 5. 해결 방법

| | 홈 | 종목 상세 |
|---|---|---|
| 질문 | "내일 장 시작 가격 오를까요?" / "지금 시세차익 기회 있어요?" | 두 시장이 어디서, 얼마나, 왜 벌어졌나 |
| 화면 | 종목별 오를 확률·예상 시작 가격, 오늘의 이슈, 1천만원 기준 시세차익 기회 | 차트 \| 호가 \| 주문 3단(경계를 끌어 너비 조절, 기본 340px, 페이지 스크롤 없음), 차트 위 '내일 아침 예상 · 오를 확률 [자세히]'·'시세차익 · 1천만원이면 약 N원 [시세차익 내기]', 차트 전체화면, 탭 줄 끝 오늘의 이슈, 개장 예측·예측 기록·투자자 동향 탭 |
| 용어 | perp → "하이퍼리퀴드", KRX·넥스트레이드 → "국내 시장", 시가 → "장 시작 가격" | 같음 (원화 환산 기준) |

**종목 상세 차트**
- 두 시장 캔들/라인 겹침, 시장별 on/off, 시장별 거래량
- 배경색으로 국장 개장(정규장·넥스트레이드)·휴장(하이퍼리퀴드만 거래) 구분, 일봉 포함
- 하이퍼리퀴드 일봉은 국내 거래일과 같은 저녁 8시~저녁 8시 기준으로 다시 묶음 (거래소 일봉은 UTC 하루라 13시간 어긋남)
- 가격 차이 패널: 장중은 진하게, 휴장 중(직전 종가 대비)은 연하게. 하이퍼리퀴드 상장일 세로선
- 따라간 정도 패널: 하이퍼리퀴드가 1% 이상 움직인 날, 그 움직임을 국내 시장이 몇 % 따라 시작했는지 막대로 (100% 점선 = 그대로)
- 휴장 중에는 예상 시작 가격선과 예상 범위, 시세차익이 생기면 그 가격에 '시세차익 내기' 버튼
- 뉴스 말풍선 (하루 1건, 출처 확인된 것만) → 누르면 요약과 원문 링크
- 이동평균, 그물망, 볼린저, 일목균형, VWAP, RSI, MACD, 펀딩비

**따라간 정도 지표** ('예측 기록' 표·차트·API 공통)
- `따라간 정도` = 08:00~08:10 국내 움직임 ÷ 밤사이 하이퍼리퀴드 움직임. 100%면 그대로 따라 시작. 차트에는 하이퍼리퀴드가 1% 이상 움직인 날만 표시 (작은 움직임은 비율이 의미 없음)
- `만난 지점` = 08:00~09:00 동안 두 가격이 만난 위치. 0이면 하이퍼리퀴드가 국내 쪽으로, 1이면 국내가 하이퍼리퀴드 쪽으로 이동

**순차익 계산 (비용 뺀 수익)**

`순차익 = |가격 차이 − 평소 차이| − 주식 수수료·세금 − perp 수수료 − 환전 비용 − 보유 중 펀딩비`

- 두 시장 가격 차이는 0으로 돌아가지 않고 '평소 수준'에서 움직임. 정규장 시간 월별 중간값이 2026년 9월 약 −0.7~+0.1%, 10월 +0.9~1.0%, 11월 +0.5% (세 종목 비슷)
- 그래서 **평소 차이 = 최근 5거래일 정규장 1시간 가격 차이의 중간값**으로 두고, 지금 차이가 평소보다 더 벌어진 만큼만 기회로 봄. 처음에는 0을 기준으로 계산해서, 평소 수준인 날에도 '1천만원 기준 약 17,000원 남아요'로 보였던 문제를 고침
- 평소 차이 ±0.1%p 안이면 화면에 '평소 수준이에요'

| 항목 | 기본값 | 근거 |
|---|---|---|
| 주식 | 왕복 수수료 0.03% + 매도세 0.20% | 2026년 코스피 증권거래세·농특세 합계로 가정 |
| perp | 왕복 0.018% | HL 기본 0.045% × HIP-3 배수 2 × growth mode 0.1 |
| 환전 | (0.05% + 호가 스프레드 절반) × 2 ÷ 레버리지 | 업비트 원화마켓 수수료, 증거금만 환전 |
| 펀딩 | 시간당 펀딩 × 1시간 | 숏이면 받고 롱이면 냄 |

- 개인은 주식 공매도가 어려워서 **perp가 쌀 때(주식 매도 필요)는 '실행 불가'로 표시**
- 모든 비용은 API 파라미터로 바꿀 수 있음

## 6. 주요 결정과 이유

| 결정 | 이유 |
|---|---|
| **환율은 원/USDC (업비트 실시간)** | perp는 USDC로 정산. 국내 투자자가 실제로 돈을 옮기는 경로가 원 → USDC라서, 은행 원/달러 환율보다 체결 가능한 값에 가까움 |
| **증권사 API는 토스증권 Open API** | 카카오페이증권은 오픈 API가 없어서, 개인이 직접 발급받아 쓸 수 있는 토스증권 Open API를 사용. 실시간 체결·호가 웹소켓, 1분봉(넥스트레이드 포함 통합 시세), 투자자 동향, 장 운영 캘린더, 주문까지 한 곳에서. 브라우저가 직접 못 붙는 웹소켓(헤더 인증·허용 IP)은 서버가 하나만 열어 나눠줌 |
| **예측·시세차익은 국내 주식 3종만, 나머지는 하이퍼리퀴드 가격만** | 하이퍼리퀴드의 한국 상품 7개(삼성전자·SK하이닉스·현대차·SK하이닉스 ADR·코스피200·EWY·KORU)를 다 보여주되, 같은 기초자산의 국내 가격이 있는 국내 주식 3종만 예측·시세차익을 계산. ADR은 보통주로 바꿀 수 없고, 코스피200은 증권사 API에 실시간 지수가 없고, EWY·KORU는 미국 ETF라 비교 대상이 없음 |
| **화면은 Vercel, API 서버는 Fly.io (고정 IP 서버 1대)** | 토스증권 Open API는 허용 IP에서만 호출되고, 토큰을 새로 받으면 이전 토큰이 바로 무효가 됨. 그래서 고정 출구 IP를 가진 서버가 항상 1대만 떠 있어야 함. Vercel·Firebase 같은 서버리스 함수는 요청마다 인스턴스가 여러 개 뜰 수 있어 토큰이 서로를 끊고, 고정 IP는 유료 옵션. Fly는 머신 1대 + 고정 출구 IP(월 $3.6)로 월 $8 안팎. 화면(정적 파일)은 Vercel이 내보내고 `/api`만 Fly로 넘김 |
| **국내 실주문은 기본 꺼둠** | 토스증권은 모의투자가 없어서 실제 돈이 나감. 서버 주인이 `TOSS_LIVE_ORDERS=1`로 켰을 때만 |
| **'국내 시장' = 정규장 + 넥스트레이드 (08:00–20:00)** | 개인이 실제로 거래할 수 있는 시간 전체. 15:30~20:00 넥스트레이드 움직임은 이미 국내에서 보이는 정보라, 이걸 예측으로 치면 실력이 부풀려짐. 그래서 기준은 20:00 마지막 가격, 대상은 08:00 재개장 가격 |
| **08:00~08:10 평균 가격으로 채점** | 첫 체결 한 건은 거래가 적어 튐. 5·10·30분 평균과 정규장 09:00을 비교해 가장 안정적인 10분 평균 선택 |
| **예측 모델은 단순 선형 + 정규분포** | 표본이 종목별 140번 남짓이라 복잡한 모델은 과적합. 설명할 수 있어야 초보가 믿음(H3). 계수 β는 1(하이퍼리퀴드 그대로) 쪽으로 당겨서 급락일 몇 번에 휘둘리지 않게 함. 계산법은 3장 '예측 계산법' |
| **장 열리기까지 남은 시간만큼 범위를 넓힘** | 금요일 밤 예측과 월요일 07:59 예측의 확신이 같으면 안 됨. 닫힌 시간대 하이퍼리퀴드 변동성 × 남은 시간 반영 |
| **홈 → 종목 상세 한 갈래** | 요약/상세 모드를 따로 두면 같은 정보가 두 번 나오고 '뭐가 다르지?' 고민이 생김. 초보 질문 2개("오를까?", "얼마 남아?")는 홈에서 답하고, 종목 상세에서는 같은 답을 차트 위 해당 가격에 붙여 보여줌 |
| **예측시장은 v2로 미룸** | 국내 사행성 규제 소지, 금융당국이 해외 perp 이용에 경고한 상황. 먼저 예측 정확도와 신뢰를 쌓는 게 순서 |
| **화면 주문은 '출시 예정' + 알림 신청, API는 기본 미리보기(dryRun)** | 프로토타입에서 실수 주문 0건이 우선. 대신 주문 버튼 클릭과 알림 신청으로 실제 수요(H4)를 잼. API 실주문은 서버 토큰 + 명시적 전환 필요, perp는 테스트넷 기본 |
| **API의 perp 주문은 에이전트 키로만 서명** | 메인 지갑 키가 서버에 들어오지 않음. 에이전트는 주문만 가능, 출금 불가 |
| **MCP는 조회 + 미리보기만** | 에이전트 오작동이 실제 돈으로 이어지지 않게 |
| **뉴스는 하루 1건, 출처 있는 것만** | 차트가 뉴스로 덮이면 안 됨. 틀린 뉴스 1건이 신뢰를 다 깎음 |
| **차트는 TradingView lightweight-charts** | Skia(CanvasKit)는 wasm만 수 MB라 첫 화면이 느려짐. 캔버스 기반, 약 57KB(gzip), 거래소에서 검증된 라이브러리. 종목 상세에서만 내려받음 |
| **디자인 토큰은 토스증권 PC, 키컬러·CTA만 카카오페이** | 카카오페이증권은 PC 버전이 없어서, 간편한 UX로 잘 알려진 토스증권 PC를 참고. 증권 사용자가 이미 익숙한 정보 밀도와 컴포넌트(패널, 칩, 호가, 검색, 필터). 하이퍼리퀴드는 그쪽 키컬러에 가까운 민트로 구분. 브랜드 구분은 노랑(#FFEB00) 하나로 충분. 폰트는 토스 전용 서체 대신 가장 가까운 공개 서체 Pretendard |
| **React 19.3.1 / Vite 8.3.5** | 최신 패치 버전이면서 실사용 2위 버전. 2025~26년 React 보안 이슈는 서버 컴포넌트 한정이라 SPA는 해당 없음. Vite는 10월 보안 패치 포함 버전 |

## 알려진 한계

- 토스증권 API는 허용 IP에서만 호출 가능. 서버 IP가 고정이어야 함
- 토스증권 토큰은 새로 발급하면 이전 토큰이 바로 무효 → 서버는 한 대(한 프로세스)로 운영
- 토스증권은 동시호가 예상체결가를 주지 않아 개장 직전 예상가는 perp 기준만 표시
- 서버 메모리 캐시라 인스턴스가 바뀌면 백테스트를 다시 계산함 (첫 요청 수 초)
- 하이퍼리퀴드 API는 간격별로 최근 캔들 5,000개만 보관 → 08:00 가격이 필요한 1시간봉은 약 7개월치. 그래서 채점 기간이 2026-04-13부터이고, 서버가 매일 쌓으면 길어짐
- 넥스트레이드 08:00 직후는 거래가 적어 10분 평균도 가끔 튈 수 있음. 현대차처럼 거래가 적은 종목은 영향이 더 큼
- 투자 권유가 아닌 참고 정보. 해외 perp는 국내 투자자 보호 대상이 아님
