# [밤사이](https://bamsai.kr/?utm_source=prd&utm_medium=document&utm_campaign=prd_summary&utm_content=title) — PRD

> 국내 장이 닫힌 밤·주말에도 해외 거래소 **하이퍼리퀴드**에서 삼성전자·SK하이닉스·현대차를 따라가는 선물(perp)이 24시간 거래됨. 이 가격을 원화로 바꿔 **장 시작 전 해외 가격과 과거 적중률**, **비용을 뺀 두 시장 가격 차이**를 웹과 API·MCP(AI 에이전트가 외부 데이터를 쓰는 표준 연결 방식)로 제공함.
> 웹앱 [**bamsai.kr**](https://bamsai.kr/?utm_source=prd&utm_medium=document&utm_campaign=prd_summary&utm_content=header) · [GitHub](https://github.com/eddyParkGG/bamsaikr) · [자세한 PRD(README)](https://github.com/eddyParkGG/bamsaikr#readme)

## 1. 해결하려는 문제

- 국내 시장(정규장 + 넥스트레이드, 08:00\~20:00)은 주 168시간 중 35%만 열림. 나머지 시간의 가격은 하이퍼리퀴드에서 달러로 정해져, 다음 날 시작 가격을 가늠하기 어려움
- 투자자들은 이미 이 가격을 직접 원화로 바꿔 공유하지만([예 1](https://gall.dcinside.com/mgallery/board/view/?id=stockus&no=16951832)), 언제 본 가격이 맞는지([예 2](https://gall.dcinside.com/mgallery/board/view/?id=krstock&no=1823148)), 오류 가격인지([예 3](https://gall.dcinside.com/mgallery/board/view/?id=stockus&no=17323425)) 모름

## 2. 타겟 고객

| 구분 | 고객 | 결정의 순간 |
|---|---|---|
| **초기** | **LLM으로 국내 주식 자동매매 봇을 운영하는 개인 투자자** (하이퍼리퀴드 병행 포함) | 개장 전(06\~08시) 포지션을 정할 때, 두 시장 가격 차이가 벌어졌을 때 |
| 확장 | 삼성전자·SK하이닉스를 거래하는 일반 투자자 | 08시 넥스트레이드가 열릴 때 바로 거래할지, 기다릴지 |

초기 타겟은 쓰는지가 호출 수로 바로 보여 검증이 빠름. 꾸준히 쓰면 그 근거로 일반 투자자 화면으로 넓힘

## 3. 가설

| # | 가설 | 상태 |
|---|---|---|
| **H1 신호** | 밤사이(20:00\~08:00) 하이퍼리퀴드 거래가 충분하면(100만 달러 이상) 그 방향대로 다음 날 08:00 국내가 시작한다 (80% 이상) | **통과: 삼성전자 88.2%, SK하이닉스 85.4%** (4/13\~11/5, 종목별 139번). 매일 '오른다'로 찍으면 52\~53% |
| **H5 에이전트 (초기)** | API·MCP를 열면 봇이 매주 반복해서 호출한다 | 11/6 MCP 공개 목록(공식 Registry, Glama) 등록. awesome MCP 목록 PR 2건 머지 뒤부터 판단 |
| H2 습관 (확장) | 밤사이 가격과 적중률을 보여주면 장 시작 전에 다시 온다 | 주식 커뮤니티 2주 게시로 측정 (11/5\~11/19) |
| H3 신뢰 | 지난 개장 기록을 같이 보여줘야 숫자를 믿는다 | 근거 열람률로 측정 |
| H4 전환 | 비용 뺀 가격 차이를 보여주면 주문 클릭으로 이어진다 | 주문 화면·출시 알림 신청으로 측정 |

- **언제 본 가격이냐가 핵심**: 방향이 맞은 비율이 21시 가격은 49%, 미국장이 닫힌 06시 가격은 86\~87% → 화면은 '오를 확률' 대신 지금 시간대의 과거 적중률을 보여줌

## 4. 검증 지표

| 지표 | 정의 | 기준 |
|---|---|---|
| **North Star** | 실제 데이터를 가져간 **주간 외부 API·MCP 호출자 수** (연결 확인·목록 사이트 점검 제외, 익명 ID로 구분) | 증가 추세, 2주 연속 호출 비율 |
| 확장 타겟 습관 | 06\~08시에 밤사이 가격을 본 주간 사용자, 첫 방문 뒤 다른 날 개장 전 재방문 비율 | 15% 이상 → 개장 전 알림 개발 / 5\~15% → 메시지 바꿔 재실험 / 5% 미만 → 가설 기각 |
| 전환 | 가격 차이 조회 → 주문 클릭 → 출시 알림 신청 | 클릭 5%, 신청 20% |
| 가드레일 | 방향 적중률 | 4주 연속 75% 미만이면 숫자 숨김 |

## 5. 해결 방식과 AI 활용

- **해결 방식**: 하이퍼리퀴드 가격 × 업비트 원/USDC 환율 + 토스증권 Open API(국내 실시간 시세·호가·투자자 동향, [SK하이닉스 종목 화면](https://bamsai.kr/s/SKHX?utm_source=prd&utm_medium=document&utm_campaign=prd_summary&utm_content=solution)에서 실제 동작)
  - ① 개장 전 가격과 시간대별 과거 적중률
  - ② 가격 차이 거래 순이익 (수수료·세금·환전·펀딩비·슬리피지·주문 시차 비용을 뺌)
  - 봇은 MCP 도구(`predict_open`, `get_arbitrage` 등)로, 사람은 웹으로 같은 숫자를 봄. 주문은 미리보기만
- **AI 활용**: Claude Code로 API 조사, 데이터 검증, 백테스트(그날 이전 데이터로만 채점), 구현. 화면을 바꿀 때마다 AI가 Chrome으로 직접 확인하고, 그 흐름을 자동 테스트로 옮김. 금융 숫자는 LLM이 아니라 시세·통계로 계산. 단계별 구현 과정은 [README의 AI 활용 과정](https://github.com/eddyParkGG/bamsaikr#ai-활용-과정)
- **AI 결과를 고친 사례**: 처음엔 저녁 가격으로 '내일 오를 확률'을 보여줌 → 21시 '+0.3%'로 올린 글 다음 날 실제 −11.9%로 시작 → 시각별로 다시 채점해 위 '언제 본 가격이냐'를 찾음 → '오를 확률'을 빼고 '미국장 마감 뒤 가격 + 시간대 적중률'로 바꿈
- **다음 액션**: ① 개장 전 알림 ② 자동 시세차익 안전장치(금액·레버리지 한도, 장 마감 전 청산, 승인 대기)

## 6. 운영·GTM

- **GTM**: 초기 타겟은 MCP 목록(공식 Registry, Glama, awesome 목록)에 등록. 확장 타겟은 디시 주식 갤러리에 게시하고 UTM으로 유입 측정
- **오픈 후 고친 것**: 아이폰 로딩 실패·화면 깨짐 / 증권사 API 호출 한도 초과(대기열·캐시) / 시세차익을 호가 체결가로 다시 계산 / 오라클 급변 방지 로직 추가(2026-07-28 SK하이닉스 1주 하한가 체결로 perp −17.9%, 롱 약 5,700만 달러 청산된 사례 대비) / 실주문은 항상 인증 토큰 필요
- **품질**: 단위 테스트 170개, 사용자 시나리오 자동 테스트 11개를 코드 올릴 때마다 실행
- **출시 전제**: 토스증권 Open API는 시세를 본인 매매 목적으로만 허용 → 실제 출시에는 정식 시세 계약 필요
