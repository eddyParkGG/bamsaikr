# [밤사이](https://bamsai.kr/?utm_source=prd&utm_medium=document&utm_campaign=submission&utm_content=title) — PRD

> 국내 시장이 닫힌 밤과 주말에도 해외 24시간 선물 거래소 **하이퍼리퀴드**에서 삼성전자·SK하이닉스·현대차 가격을 따라가는 무기한 선물(perp)이 거래됨. 이 가격을 원화로 바꿔, 장 시작 전 판단에 쓸 **밤사이 해외 가격과 과거에 국내 시장이 그 방향대로 열린 비율**, **비용을 뺀 두 시장 가격 차이 거래 기회**를 API·MCP(AI 에이전트가 외부 데이터를 불러 쓰는 표준 연결 방식)와 웹 화면으로 제공함.
> 웹앱 [**bamsai.kr**](https://bamsai.kr/?utm_source=prd&utm_medium=document&utm_campaign=submission&utm_content=header) · [GitHub](https://github.com/eddyParkGG/bamsaikr) · [자세한 README](https://github.com/eddyParkGG/bamsaikr#readme)

## 1. 해결하려는 문제

- 국내 시장(정규장 09:00\~15:30 + 대체거래소 넥스트레이드, 합쳐서 08:00\~20:00)은 주 168시간 중 35%만 열림. 닫힌 65% 동안의 가격은 하이퍼리퀴드에서 정해지지만 달러(USDC, 달러와 1:1인 코인) 표시라, 다음 날 시작 가격에 얼마나 반영될지 개인이 판단하기 어려움
- 실제 투자자들은 이미 이 가격을 찾아보고 있음. 주식 커뮤니티에서 개장 전·주말마다 직접 원화로 바꿔 공유하지만([예 1](https://gall.dcinside.com/mgallery/board/view/?id=stockus&no=16951832) "삼전 24.4 하닉 170 / 월요일 서킷 확정"), 언제 본 가격이 맞는지 모르고([예 2](https://gall.dcinside.com/mgallery/board/view/?id=krstock&no=1823148) "새벽에 삼전 390000원이라길래 … 음전"), 오류 가격과 구분하지 못함([예 3](https://gall.dcinside.com/mgallery/board/view/?id=stockus&no=17323425) "오류로 -30퍼 찍을 때 하이퍼리퀴드에도 반영되냐")

## 2. 타겟 고객

| 구분 | 고객 | 결정의 순간 |
|---|---|---|
| **초기** | **LLM으로 국내 주식 자동매매 봇을 운영하는 개인 투자자** (하이퍼리퀴드에서 한국 주식 perp를 함께 거래하는 사람 포함). 지금은 하이퍼리퀴드 가격·환율·국내 시세를 직접 모아 맞추고 검증까지 해야 함 | 미국장이 닫힌 뒤(06\~08시) 개장 전 포지션을 정할 때, 두 시장 가격 차이가 평소보다 벌어졌을 때 |
| 확장 | 삼성전자·SK하이닉스 등을 거래하는 일반 투자자 | 아침 8시 넥스트레이드가 열릴 때 바로 거래할지, 기다릴지 |

초기 타겟은 쓰는지 안 쓰는지가 호출 수로 바로 보여 검증이 빠름. 숫자를 꾸준히 쓰면 그 근거로 증권 앱의 일반 투자자 화면으로 넓힘

## 3. 가설

| # | 가설 | 상태 |
|---|---|---|
| **H1 신호** | 국내가 닫힌 20:00\~08:00에 하이퍼리퀴드에서 충분히(밤사이 거래대금 100만 달러 이상) 거래됐다면, 그 방향대로 다음 날 08:00 국내 시장이 시작한다 (80% 이상) | **통과: 삼성전자 88.2%, SK하이닉스 85.4%** (2026-04-13\~11-05, 종목별 139번) |
| H2 습관 (확장 타겟) | 밤사이 가격과 '그 방향대로 열린 비율'을 보여주면 장 시작 전에 다시 온다 | 진행 중. 주식 커뮤니티 게시로 측정 |
| H3 신뢰 | 지난 개장 기록을 같이 보여줘야 숫자를 믿는다 | 근거 열람률로 측정 |
| H4 전환 | 비용 뺀 가격 차이 거래 기회를 보여주면 주문 클릭으로 이어진다 | 주문 화면·출시 알림 신청으로 측정 |
| **H5 에이전트 (초기 타겟)** | 봇 운영자에게 API·MCP를 열면 봇이 매주 반복해서 호출한다 | 진행 중. 11/6 MCP 공개 목록(공식 MCP Registry, Glama)에 등록 |

- **100만 달러 기준**: 밤 12시간 거래대금이 이보다 적으면 주문 몇 건에도 가격이 흔들려 적중률이 67%로 떨어짐(이상은 86%). 삼성전자(보통 밤 약 2,500만 달러)·SK하이닉스(약 1.3억 달러)는 거의 매일 넘고, 거래가 적은 현대차(약 23만 달러)를 걸러내는 기준
- **H1을 믿을 수 있는 이유**: 같은 기간 국내 시장이 오르며 시작한 날은 52\~53%뿐이라, 하이퍼리퀴드를 안 보고 매일 '오른다'고 찍으면 절반 정도만 맞음. 하이퍼리퀴드 방향을 따르면 85\~88%가 맞으니 그 차이가 신호의 값. 비교 가격은 **08:00 직전(07:59)** 하이퍼리퀴드 가격. perp 가격은 국내 체결가를 기준 가격(오라클)으로 삼아서, 08:00 넥스트레이드 첫 체결 직후에는 몇 주만으로도 튈 수 있기 때문
- **언제 본 가격이냐가 중요**: 21시 가격은 49%, 미국장이 닫힌 06시 가격은 86\~87%만 방향이 맞음 → 화면은 '오를 확률' 대신 지금 시간대의 과거 적중률만 보여줌

## 4. 검증 지표

| 지표 | 정의 | 기준 |
|---|---|---|
| **North Star** | 밤사이 API·MCP로 실제 데이터를 가져간 **주간 외부 호출자 수**. 연결만 해 본 호출, MCP 목록 사이트의 자동 점검은 제외. 호출자는 IP·브라우저 정보로 만든 되돌릴 수 없는 익명 ID로 구분 | 증가 추세, 2주 연속 호출 비율 |
| 확장 타겟 습관 | 미국장이 닫힌 뒤 06\~08시에 밤사이 가격을 본 주간 사용자, 첫 방문 뒤 다른 날 개장 전에 다시 온 비율 | 15% 이상 → 개장 전 알림 개발 / 5\~15% → 메시지 바꿔 재실험 / 5% 미만 → 습관 가설 기각 |
| 전환 | 가격 차이 조회 → 주문 클릭 → 출시 알림 신청 | 클릭 5%, 신청 20% |
| 가드레일 | 방향 적중률 | 4주 연속 75% 미만이면 숫자 숨김 |

H2는 제출일(11/8)까지 게시하며 GA로 보고(11/6 이후 전체 방문), 방문 200명에 못 미치면 인터뷰 등 다른 방법으로 보완

## 5. 프로토타입: 해결 방식과 AI 활용

- **해결 방식**: 하이퍼리퀴드 가격을 업비트의 원/USDC 시세로 원화 환산하고, 토스증권 Open API(국내 시세·호가·투자자 동향)와 합쳐 ① 개장 전 가격과 시간대별 과거 적중률 ② 가격 차이 거래 순이익을 계산. 순이익에서는 수수료·세금·환전 비용, 펀딩비(perp를 들고 있는 동안 1시간마다 내거나 받는 비용), 슬리피지(호가가 밀려 불리하게 체결되는 차이), 두 주문 사이 시차 동안의 가격 변동을 뺌. 봇은 MCP 도구(`predict_open`, `get_arbitrage` 등)로, 사람은 웹 화면으로 같은 숫자를 봄. 실제 주문은 보내지 않고 미리보기만 함
- **AI 활용**: Claude Code로 API 조사, 데이터 검증, 백테스트(과거 데이터로 하루씩 앞으로 가며 그날 이전 정보만으로 채점), 구현. 화면을 바꿀 때마다 AI가 Chrome을 직접 띄워 누르고 확인한 뒤, 그 흐름을 사용자 시나리오 자동 테스트로 옮겨 코드를 올릴 때마다 자동 실행. 금융 수치는 LLM이 아니라 실제 시세와 통계로 계산
- **AI 결과를 고친 사례**: 저녁 9시 '내일 +0.3%'가 실제 −11.9%로 빗나감 → 시각별로 다시 채점해 21시 49% vs 06시 86\~87%를 찾음 → '오를 확률'을 빼고 '미국장 마감 뒤 가격 + 과거 비율'로 바꿈
- **한계**: perp 가격은 기준 가격(오라클)에 묶여 국내 개장 직후 얇은 체결 하나로 급변할 수 있음(2026-07-28 넥스트레이드에서 SK하이닉스 1주가 하한가에 체결되자 perp −17.9%). 토스증권 Open API 약관은 시세를 본인 매매 목적으로만 허용해, 실제 출시는 증권사가 계약한 정식 시세를 전제로 함
