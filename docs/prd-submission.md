# 밤사이 — PRD (제출용 요약)

> 국내 시장이 닫힌 밤과 주말에도 해외 24시간 선물 거래소 **하이퍼리퀴드**에서 한국 주식이 거래됨. 이 가격을 원화로 바꿔 **① 밤사이 해외 가격과 과거에 국내 시장이 그 방향대로 열린 비율**, **② 비용을 뺀 두 시장 사이 가격 차이 거래 기회**를 API·MCP와 웹 화면으로 제공함.
> 웹앱 **https://bamsai.kr** · GitHub https://github.com/eddyParkGG/bamsaikr · 자세한 내용 [README](../README.md)
>
> **과제 해석**: AI(Claude Code)로 문제를 찾고 직접 만들고, 고객의 AI 에이전트가 같은 숫자를 바로 쓰도록 API·MCP로 연 제품. 금융 수치는 LLM이 아니라 실제 시세와 통계로 계산함

## 1. 문제와 타겟 고객

- **문제**: 국내 시장(정규장 + 넥스트레이드)은 주 168시간 중 35%만 열림. 닫힌 65% 동안의 가격은 하이퍼리퀴드에서 정해지지만 달러 표시라, 다음 날 시작 가격에 얼마나 반영될지 개인은 알기 어려움
- **계기 — 투자자들이 이미 하던 행동**: 주식 커뮤니티에서 개장 전·주말마다 하이퍼리퀴드 가격을 직접 원화로 바꿔 공유함(디시 '하이퍼리퀴드 삼전' 검색만 2\~10월 15건 이상). 예: ["삼전 24.4 하닉 170 / 월요일 서킷 확정"](https://gall.dcinside.com/mgallery/board/view/?id=stockus&no=16951832), ["새벽에 삼전 390000원이라길래 … 음전"](https://gall.dcinside.com/mgallery/board/view/?id=krstock&no=1823148), ["갭락이라고 생각하면 하이퍼리퀴드에 삼전선물 숏"](https://gall.dcinside.com/mgallery/board/view/?id=krstock&no=3309173), ["오류로 -30퍼 찍을 때 하이퍼리퀴드에도 반영되냐"](https://gall.dcinside.com/mgallery/board/view/?id=stockus&no=17323425) → 직접 환산하고, 언제 본 가격이 맞는지 모르고, 오류 가격과 구분하지 못함
- **초기 타겟: LLM으로 국내 주식 자동매매 봇을 운영하는 개인 투자자** (하이퍼리퀴드 한국 주식 perp를 함께 거래하는 사람 포함). 지금은 하이퍼리퀴드 가격·환율·국내 시세를 직접 모아 맞추고 검증·비용 계산까지 해야 함. 쓰는지가 호출 수로 바로 보여 검증이 빠름
- **결정의 순간**: 미국장이 닫힌 뒤(06\~08시) 개장 전 포지션을 정할 때, 두 시장 가격 차이가 평소보다 벌어졌을 때. 하이퍼리퀴드가 밤새 1% 넘게 움직인 날 08\~09시에 국내 가격이 하이퍼리퀴드 쪽으로 간 경우 72\~75%, 반대 10\~11%
- **확장 타겟**: 삼성전자·SK하이닉스 등을 거래하는 일반 투자자. 초기 타겟이 숫자를 꾸준히 쓰면 증권 앱 화면으로 넓힘

## 2. 가설과 검증

| # | 가설 | 결과·상태 |
|---|---|---|
| **H1 신호** | 국내가 닫힌 20:00\~08:00에 하이퍼리퀴드에서 충분히(100만 달러 이상) 거래됐다면, 그 방향대로 다음 날 08:00 국내 시장이 시작한다 (80% 이상) | **통과: 삼성전자 88.2%, SK하이닉스 85.4%** (2026-04-13\~11-05, 종목별 139번) |
| **H5 에이전트** (초기) | 봇 운영자에게 API·MCP를 열면 봇이 매주 반복해서 호출한다 | 진행 중. 11/6 공식 MCP Registry·Glama 등록, MCP 목록 PR 2건 |
| H2 습관 (확장) | 밤사이 가격과 '그 방향대로 열린 비율'을 보여주면 장 시작 전에 다시 온다 | 진행 중. 디시 주식 갤러리 게시, 개장 전 재방문 ≥ 15%면 알림 개발 |
| H4 전환 (별도) | 비용 뺀 가격 차이 거래 기회를 보여주면 주문 클릭으로 이어진다 | 클릭 ≥ 5%, 출시 알림 신청 ≥ 20% |

- **H1 채점**: 전날 20:00 국내 마지막 가격 대비 **08:00 직전(07:59) 하이퍼리퀴드 가격**과 08:00\~08:10 국내 평균 가격의 방향 비교. 08:00 넥스트레이드 첫 체결이 오라클에 들어가 perp가 튀는 순간을 피하려고 직전 가격을 씀
- **비교 기준**: 국내가 오르며 열린 비율은 52\~53%(찍기 수준). EWY·코스피200 perp도 방향은 83\~87%로 비슷해, 가치는 '종목만의 예측력'이 아니라 **닫힌 시간에 정해지는 가격을 종목별 원화로 보여주는 것**
- **언제 본 가격이냐**: 21시 가격은 49%, 미국장이 닫힌 06시 가격은 86\~87%만 맞음 → '오를 확률' 대신 지금 시간대의 과거 적중률만 보여줌
- **H2 보완**: 제출일(11/8)까지 게시하며 GA로 봄(11/6 이후 전체 방문 기준). 방문 200명에 못 미치면 인터뷰 등 다른 방법으로 보완

## 3. 해결 방법과 지표

| 대상 | 형태 | 핵심 |
|---|---|---|
| **초기 타겟** | API · MCP | `predict_open`(미국장 마감 뒤 원화 가격 + 시간대별 적중률), `get_arbitrage`(비용 뺀 가격 차이), `get_convergence_history`(지난 개장 기록), `preview_pair_order`(주문 미리보기). 키 없이 IP당 1분 300회 |
| 확장 타겟 | 홈 · 소개 | 종목 카드(국내 가격 vs 해외 가격, "과거 이 시간대 n%가 이 방향대로 열렸어요"), 계산 방법과 적중률 공개 |
| 별도 트랙 | 종목 상세 주문 | 가격 차이를 보다가 바로 주문까지 하고 싶은 사용자가 있는지 확인하려고 주문 화면과 출시 알림 신청까지 만듦. 실제 주문은 보내지 않음 |

- **가격 차이 거래**: 하이퍼리퀴드 지갑과 국내 계좌에 미리 자금을 둔 상태에서, 차이가 평소(최근 5거래일 중간값)보다 벌어지면 비싼 쪽을 팔고 싼 쪽을 사서 평소로 돌아올 때 정리. 무위험 차익이 아님
  - 순이익 = |지금 차이 − 평소 차이| − **슬리피지(1천만원어치 호가를 쌓은 체결가)** − **주문 간 시차 비용(1분 변동성 × √(3초/60초))** − 수수료·세금·환전·펀딩비. 호가 잔량이 모자라면 채울 수 있는 금액까지만
- **North Star**: 밤사이 API·MCP로 데이터를 조회한 **주간 외부 호출자 수**(GA `api_call`). 보조: 개장 전 `predict_open` 호출, 2주 연속 호출 비율. 확장 타겟은 06\~08시에 밤사이 가격을 본 주간 사용자
- **가드레일**: 방향 적중이 4주 연속 75% 미만이면 숫자 숨김

## 4. AI 활용, 품질, 운영

- **AI로 만들기**: Claude Code로 API 조사, 데이터 검증, walk-forward 백테스트, 구현. 화면을 바꿀 때마다 AI가 Chrome을 직접 띄워 누르고 스크린샷·콘솔·네트워크로 확인한 뒤 PR을 올림
- **AI 결과를 고친 사례**: 저녁 9시 '내일 +0.3%'가 실제 −11.9%로 빗나감 → 시각별로 다시 채점(21시 49% vs 06시 86\~87%) → '오를 확률'을 빼고 '미국장 마감 뒤 가격 + 과거 비율'로 바꿈
- **테스트**: 단위 테스트 27개(시세차익 체결가·시차, 장 시간, 미국장 단계, 호출 제한) + E2E 7개(홈 카드, 20:00 장 전환, 차트 조작, 1분봉 새 봉 생성과 밀림, 주문 클릭 시 실제 주문 0건). PR마다 CI가 타입·단위·빌드·E2E 실행
- **장애 대응**: `/api/health`로 데이터 소스별 마지막 성공 시각 확인, 장애 유형별 런북. 운영 중 고친 것: iPhone 로딩 실패(CDN 압축), 토스 API 한도 초과(그룹별 대기열·증분 캐시), 토스 오류 시 서버 종료
- **한계**: ① 하이퍼리퀴드 perp는 오라클에 묶여 있음. 7/28 08:00 넥스트레이드에서 SK하이닉스 1주가 하한가에 체결되자 perp가 17.9% 급락하고 약 5,700만 달러 롱이 청산됨(보도 기준). 다음 액션: 급변 구간 표시·평균 가격 사용, 시세차익은 실제 호가로 계산하되 청산 위험 경고 ② 토스증권 Open API 약관은 시세를 본인 매매 목적으로만 허용해, 실제 출시는 증권사가 계약한 정식 시세를 전제로 함
