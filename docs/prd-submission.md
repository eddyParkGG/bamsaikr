# 밤사이 — PRD (제출용 요약)

> 국내 시장이 닫힌 밤과 주말에도 24시간 운영되는 해외 선물 탈중앙 거래소 **하이퍼리퀴드**에서 한국 주식이 거래됨. 이 가격을 원화로 바꿔 **① 밤사이 해외 가격과, 과거에 국내 시장이 그 방향대로 열린 비율**, **② 두 시장 사이 가격 차이 거래 기회**를 알려줌.
> 웹앱 **https://bamsai.kr** · GitHub https://github.com/eddyParkGG/bamsaikr · 자세한 내용 [README](../README.md)
>
> **과제 해석**: 'AI를 활용한 투자 프로덕트'를 ① AI(Claude Code)로 문제를 찾고 직접 만들고, ② 고객의 AI 에이전트가 같은 숫자를 바로 쓰도록 API·MCP로 연 제품으로 해석함. 금융 수치는 LLM이 만들지 않고 실제 시세와 통계로 계산함 (틀린 숫자를 그럴듯하게 만드는 위험을 피하려고)

## 1. 문제, 고객, 결정의 순간

- **문제**: 국내 시장(정규장 + 넥스트레이드, 08:00–20:00)은 주 168시간 중 35%만 열림. 나머지 65% 동안 생긴 일이 다음 날 시작 가격에 얼마나 반영될지 개인은 알 방법이 없음
- **답이 있는 곳**: 하이퍼리퀴드에서 한국 주식 perp가 24시간 거래됨(SK하이닉스 24시간 거래대금 약 5.4억 달러). 달러(USDC) 표시라 원화 환산이 필요
- **핵심 고객**: 삼성전자·SK하이닉스를 보유한 직장인 투자자. 아직 고객 근거(인터뷰·행동 데이터)는 없음 → 2장 H2에서 보완
- **결정의 순간 — 아침 8시 넥스트레이드가 열릴 때 바로 사고팔지, 기다릴지.** 하이퍼리퀴드가 밤새 1% 넘게 움직인 날, 08\~09시에 국내 가격이 하이퍼리퀴드 가격 쪽으로 가서 만난 경우가 72\~75%, 반대는 10\~11% (삼성전자·SK하이닉스, 2026-04\~11). 개장 직후 국내 가격이 하이퍼리퀴드 원화 가격과 크게 벌어져 있으면 그쪽으로 좁혀질 가능성이 큼. 예: 11/6 삼성전자는 하이퍼리퀴드 07시 −9.5%, 08:00\~08:10 평균 −11.9%로 과하게 시작한 뒤 10:28 −7.4%로 되돌아옴
- **확장 고객 (별도 트랙)**: ① 하이퍼리퀴드 지갑(USDC)과 국내 증권 계좌에 **이미 양쪽 자금을 둔** 겸업 트레이더(가격 차이 거래) ② AI 툴로 자기 투자 도구를 만드는 고객(API·MCP)

## 2. 가설과 검증

| # | 가설 | 결과·상태 |
|---|---|---|
| **H1 신호** | 국내가 모두 닫힌 20:00\~08:00에 하이퍼리퀴드에서 충분히(100만 달러 이상) 거래됐다면, 그 방향대로 다음 날 08:00 국내 시장이 시작한다 (80% 이상) | **통과: 삼성전자 88.2%, SK하이닉스 85.4%** (11/5 기준, 매일 재계산). 현대차는 거래 충분한 밤이 7번뿐이라 보류 |
| H2 습관 | 밤사이 해외 가격과 '그 방향대로 열린 비율'을 보여주면 장 시작 전에 다시 온다 | 진행 중. 개장 전 재방문 ≥ 15%면 알림 개발 |
| H3 신뢰 | 지난 개장 기록을 같이 보여줘야 믿고 행동한다 | 근거 열람률 ≥ 10% |
| H4 전환 | 비용 뺀 가격 차이 거래 기회를 보여주면 주문 클릭으로 이어진다 (확장 트랙) | 클릭 ≥ 5%, 출시 알림 신청 ≥ 20% |
| H5 에이전트 | API·MCP를 열면 화면 밖 호출이 생긴다 | 주 1,000회 (GA `api_call`) |

- **H1 채점**: 전날 20:00 국내 마지막 가격 대비 08:00 하이퍼리퀴드 가격과 08:00\~08:10 국내 평균 가격의 방향 비교. 2026-04-13\~11-05, 종목별 139번. 100만 달러 기준은 거래대금 구간별 적중률을 비교해 정했고(미만 67% / 이상 86%), 기준을 0\~500만 달러로 바꿔도 85\~89%로 거의 같음
- **비교 기준**: 같은 기간 국내가 오르며 열린 비율은 52\~53%(찍기 수준). 다른 하이퍼리퀴드 한국 신호도 방향은 비슷함(EWY perp 85\~87%, 코스피200 perp 83\~84%) → 가치는 '종목 perp만의 방향 예측력'이 아니라 **닫힌 시간에 정해지는 가격을 종목별 원화 가격으로 보여주는 것**. 다음 단계: 시작 가격 크기 오차를 신호별로 비교
- **언제 본 가격이냐**: 21시 가격은 49%, 미국장이 닫힌 06시 가격은 86\~87%만 방향이 맞음(평일 밤 108번) → 화면은 '오를 확률' 대신 지금 시간대의 과거 적중률만 보여줌
- **H2 진행과 보완**: 11/5부터 디시 주식 갤러리에 게시 중(11/6까지 4번, 글마다 UTM으로 GA 유입 구분). 제출일(11/8)까지 계속 게시하며 GA로 방문·개장 전 재방문을 봄. 판단 최소 표본(방문 200명, 클릭률 3% 가정 시 조회 약 6,700회)에 못 미치면 정량 결론을 미루고 **보유자 인터뷰 등 다른 방법**(언제 무엇을 보고 결정하는지 확인)으로 보완

## 3. 해결 방법 (프로토타입)

| 범위 | 화면 | 핵심 |
|---|---|---|
| **핵심 (증권 앱에 들어갈 범위)** | 홈 | 종목 카드. 장중: 국내 지금 vs 미국장 닫힌 뒤·국내 개장 직전 글로벌 가격. 장 마감 후: 국내 종가 vs 지금 글로벌 가격 + 미국장 단계 + "과거 이 시간대 n%가 이 방향대로 열렸어요" |
| 핵심 | 지난 개장 기록 · 소개 | 매일 다시 계산하는 적중률과 계산 방법 공개 (H3) |
| 확장 트랙 | 종목 상세 | 두 시장을 겹친 차트·호가·주문(출시 예정 + 알림 신청), 가격 차이 거래 기회 |
| 확장 트랙 | API · MCP | 조회와 주문 미리보기. 실제 주문은 보내지 않음 |

- **가격 차이 거래 (화면 이름 '시세차익')**: 하이퍼리퀴드 지갑(USDC)과 국내 증권 계좌에 **미리 자금을 둔 상태**에서, 두 가격 차이가 평소(최근 5거래일 중간값)보다 벌어졌을 때 비싼 쪽을 팔고 싼 쪽을 사서, 차이가 평소로 돌아오면 정리하는 거래. **무위험 차익이 아니라 평소 차이로 돌아온다는 데 거는 거래**임
  - 계산: |지금 차이 − 평소 차이| − 주식 수수료·세금 − 하이퍼리퀴드 수수료 − 환전 비용 − 펀딩비. 남으면 '+N원', 아니면 '아직 기회가 없어요'
  - 아직 반영 못 한 위험: 차이가 언제 좁혀질지 모름(펀딩비는 1시간 보유로 가정), 호가 잔량·슬리피지, 두 주문 사이 시차, 양쪽에 자금을 묶어 두는 부담. 개인은 공매도가 어려워 주식을 팔아야 하는 방향은 기회로 세지 않음
- **perp 권유 범위**: 핵심 화면은 국내 주식 판단까지만. perp 거래는 이미 하이퍼리퀴드를 쓰는 확장 트랙 고객에게만 보여주고, 증권 앱 버전에서는 국내 주문만 연결

## 4. 지표와 결정 규칙

- **North Star**: 미국장이 닫힌 뒤 국내 시작 전(06:00\~08:00)에 밤사이 가격을 실제로 본(`prediction_view`, `kst_window=preopen`) 주간 사용자. 단순 방문은 세지 않음. 11/6 측정 시작, 첫 개장 전 집계는 11/9(월)
- **판단 규칙**: 개장 전 재방문 15% 이상 → 개장 전 알림 개발 / 5\~15% → 메시지 바꿔 재실험 / 5% 미만 → 습관 가설 기각, 연휴 갭 리포트 같은 이벤트형으로 전환
- **가드레일**: 방향 적중이 4주 연속 75% 미만이면 숫자 숨김. 주문 클릭 중 레버리지 5배 이상 비중 감시
- 출시 단계별 목표(주간 사용자 수 등)는 아직 가정이며, 첫 실험과 인터뷰 결과로 다시 정함

## 5. AI 활용과 운영

- **AI는 만드는 도구로**: Claude Code로 API 스펙 조사, 데이터 검증(환산가·통합 시세 차이), walk-forward 백테스트, 구현, 브라우저 QA, 운영 장애 분석
- **AI 결과를 고친 사례**: 저녁 9시 '내일 +0.3%'가 실제 −11.9%로 빗나감 → 시각별로 다시 채점(21시 49% vs 06시 86\~87%) → '오를 확률'을 빼고 '미국장 마감 뒤 가격 + 과거 비율'로 바꿈. 외부 AI 리뷰는 항목별로 채택·거절을 나눠 결정
- **운영하며 고친 것 (11/6)**: CDN 압축 오류로 iPhone 로딩 실패 → 서버 gzip / 토스 API 그룹별 한도 초과 → 그룹별 대기열·증분 캐시(1\~2초마다 → 분당 0\~2회) / 과거 가격을 그 시각 환율로 환산 / API·MCP 사용량을 GA로 측정(H5)
- **한계**: 토스증권 Open API 약관은 시세를 본인 매매 목적으로만 허용함. 공개 프로토타입은 이 조건을 넘을 수 있어, 실제 출시는 증권사가 계약한 정식 시세를 전제로 함
