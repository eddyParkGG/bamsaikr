# 밤사이 — PRD

> 국내 시장이 닫힌 밤과 주말에도 해외 24시간 선물 거래소 **하이퍼리퀴드**에서 한국 주식이 거래됨. 이 가격을 원화로 바꿔, 장 시작 전 판단에 쓸 **밤사이 해외 가격과 과거에 국내 시장이 그 방향대로 열린 비율**, **비용을 뺀 두 시장 가격 차이 거래 기회**를 API·MCP와 웹 화면으로 제공함.
> 웹앱 [**bamsai.kr**](https://bamsai.kr/?utm_source=prd&utm_medium=document&utm_campaign=submission) · [GitHub](https://github.com/eddyParkGG/bamsaikr) · [자세한 README](https://github.com/eddyParkGG/bamsaikr#readme)

## 1. 해결하려는 문제

- 국내 시장(정규장 + 넥스트레이드)은 주 168시간 중 35%만 열림. 닫힌 65% 동안의 가격은 하이퍼리퀴드에서 정해지지만 달러 표시라, 다음 날 시작 가격에 얼마나 반영될지 개인이 판단하기 어려움
- 실제 투자자들은 이미 이 가격을 찾아보고 있음. 주식 커뮤니티에서 개장 전·주말마다 직접 원화로 바꿔 공유하지만([예 1](https://gall.dcinside.com/mgallery/board/view/?id=stockus&no=16951832) "삼전 24.4 하닉 170 / 월요일 서킷 확정"), 언제 본 가격이 맞는지 모르고([예 2](https://gall.dcinside.com/mgallery/board/view/?id=krstock&no=1823148) "새벽에 삼전 390000원이라길래 … 음전"), 오류 가격과 구분하지 못함([예 3](https://gall.dcinside.com/mgallery/board/view/?id=stockus&no=17323425) "오류로 -30퍼 찍을 때 하이퍼리퀴드에도 반영되냐")

## 2. 타겟 고객

| 구분 | 고객 | 결정의 순간 |
|---|---|---|
| **초기** | **LLM으로 국내 주식 자동매매 봇을 운영하는 개인 투자자** (하이퍼리퀴드 한국 주식 perp를 함께 거래하는 사람 포함). 지금은 하이퍼리퀴드 가격·환율·국내 시세를 직접 모아 맞추고 검증까지 해야 함 | 미국장이 닫힌 뒤(06\~08시) 개장 전 포지션을 정할 때, 두 시장 가격 차이가 평소보다 벌어졌을 때 |
| 확장 | 삼성전자·SK하이닉스 등을 거래하는 일반 투자자 | 아침 8시 넥스트레이드가 열릴 때 바로 거래할지, 기다릴지 |

초기 타겟은 쓰는지 안 쓰는지가 호출 수로 바로 보여 검증이 빠름. 숫자를 꾸준히 쓰면 그 근거로 증권 앱의 일반 투자자 화면으로 넓힘

## 3. 가설

| # | 가설 | 상태 |
|---|---|---|
| **H1 신호** | 국내가 닫힌 20:00\~08:00에 하이퍼리퀴드에서 충분히(100만 달러 이상) 거래됐다면, 그 방향대로 다음 날 08:00 국내 시장이 시작한다 (80% 이상) | **통과: 삼성전자 88.2%, SK하이닉스 85.4%** (2026-04-13\~11-05, 종목별 139번) |
| **H5 에이전트** (초기) | 봇 운영자에게 API·MCP를 열면 봇이 매주 반복해서 호출한다 | 진행 중. 11/6 공식 MCP Registry·Glama 등록 |
| H2 습관 (확장) | 밤사이 가격과 '그 방향대로 열린 비율'을 보여주면 장 시작 전에 다시 온다 | 진행 중. 주식 커뮤니티 게시로 측정 |
| H4 전환 | 비용 뺀 가격 차이 거래 기회를 보여주면 주문 클릭으로 이어진다 | 주문 화면·출시 알림 신청으로 측정 |

- **H1을 믿을 수 있는 이유**: 국내가 오르며 열린 비율은 52\~53%(찍기 수준)라 오르는 장 덕분이 아님. 비교 가격은 08:00 넥스트레이드 첫 체결이 오라클에 들어가 튀는 순간을 피해 **08:00 직전(07:59)** 하이퍼리퀴드 가격
- **언제 본 가격이냐가 중요**: 21시 가격은 49%, 미국장이 닫힌 06시 가격은 86\~87%만 방향이 맞음 → 화면은 '오를 확률' 대신 지금 시간대의 과거 적중률만 보여줌

## 4. 검증 지표

| 지표 | 정의 | 기준 |
|---|---|---|
| **North Star** | 밤사이 API·MCP로 데이터를 조회한 **주간 외부 호출자 수** (GA `api_call`, 목록 사이트 점검 제외) | 증가 추세, 2주 연속 호출 비율 |
| 확장 타겟 습관 | 미국장이 닫힌 뒤 06\~08시에 밤사이 가격을 본 주간 사용자, 첫 방문 뒤 개장 전 재방문율 | 15% 이상 → 개장 전 알림 개발 / 5\~15% → 메시지 바꿔 재실험 / 5% 미만 → 습관 가설 기각 |
| 전환 | 가격 차이 조회 → 주문 클릭 → 출시 알림 신청 | 클릭 5%, 신청 20% |
| 가드레일 | 방향 적중률 | 4주 연속 75% 미만이면 숫자 숨김 |

H2는 제출일(11/8)까지 게시하며 GA로 보고(11/6 이후 전체 방문), 방문 200명에 못 미치면 인터뷰 등 다른 방법으로 보완

## 5. 프로토타입: 해결 방식과 AI 활용

- **해결 방식**: 하이퍼리퀴드 가격을 업비트 원/USDC로 환산하고, 토스증권 Open API(국내 시세·호가·투자자 동향)와 합쳐 ① 개장 전 가격과 시간대별 과거 적중률 ② 가격 차이 거래 순이익(호가 체결가로 본 슬리피지, 주문 간 시차, 수수료·세금·환전·펀딩비 차감)을 계산. 봇은 MCP 도구(`predict_open`, `get_arbitrage` 등)로, 사람은 웹 화면으로 같은 숫자를 봄. 실제 주문은 보내지 않고 미리보기만 함
- **AI 활용**: Claude Code로 API 조사, 데이터 검증, walk-forward 백테스트, 구현. 화면을 바꿀 때마다 AI가 Chrome을 직접 띄워 누르고 확인한 뒤, 그 흐름을 E2E 테스트로 옮겨 PR마다 CI로 실행. 금융 수치는 LLM이 아니라 실제 시세와 통계로 계산
- **AI 결과를 고친 사례**: 저녁 9시 '내일 +0.3%'가 실제 −11.9%로 빗나감 → 시각별로 다시 채점해 21시 49% vs 06시 86\~87%를 찾음 → '오를 확률'을 빼고 '미국장 마감 뒤 가격 + 과거 비율'로 바꿈
- **한계**: 하이퍼리퀴드 perp는 오라클에 묶여 국내 개장 직후 얇은 체결 하나로 급변할 수 있음(2026-07-28 SK하이닉스 −17.9%). 토스증권 Open API 약관은 시세를 본인 매매 목적으로만 허용해, 실제 출시는 증권사가 계약한 정식 시세를 전제로 함
