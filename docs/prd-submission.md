# 밤사이 — PRD (제출용 요약)

> 국내 시장이 닫힌 밤과 주말에도 24시간 운영되는 해외 선물 탈중앙 거래소 **하이퍼리퀴드**에서 한국 주식이 거래됨.
> 이 가격을 원화로 바꿔 **① 내일 아침 국내 시장이 오를지 내릴지**, **② 지금 두 시장 사이 시세차익 기회가 있는지** 알려줌.
> 자세한 내용: [README](../README.md)

## 1. 문제와 고객

| | 내용 |
|---|---|
| **문제** | 국내 시장(정규장 + 넥스트레이드, 08:00–20:00)은 주 168시간 중 35%만 열림. 나머지 65% 동안 생긴 일이 다음 날 장 시작 가격에 어떻게 반영될지 개인은 알 방법이 없음 |
| **답이 있는 곳** | 하이퍼리퀴드 한국 주식 perp는 24시간 거래 (SK하이닉스 24시간 거래대금 약 5.4억 달러). 단, 달러(USDC) 표시라 원화 환산·수수료 계산이 필요 |
| **핵심 고객** | 삼성전자·SK하이닉스를 보유한 30~40대 직장인. 아침 8시 국내 시장이 열리기 전에 매일 판단할 일이 있음 |
| **확장 고객** | 주식·코인 겸업 트레이더(시세차익), 에이전트 빌더(API·MCP) |

## 2. 가설과 검증

| # | 가설 | 상태 |
|---|---|---|
| **H1 신호** | 국내 시장이 모두 닫힌 20:00~08:00에 하이퍼리퀴드가 움직인 방향대로 다음 날 08:00 국내 시장이 시작한다 (80% 이상) | **삼성전자 85.8%·SK하이닉스 85.4% 통과, 현대차 66.7% 미달** |
| H2 가치 | '오를 확률'을 보여주면 장 시작 전에 다시 온다 | 커뮤니티 4일 실험 예정 (개장 전 재방문 ≥ 15%) |
| H3 신뢰 | 지난 예측 기록을 같이 보여줘야 믿고 행동한다 | 근거 열람률 ≥ 10% |
| H4 전환 | 비용 뺀 시세차익 기회를 보여주면 주문 버튼 클릭으로 이어진다 | 클릭 ≥ 5%, 출시 알림 신청 ≥ 20% |
| H5 에이전트 | API·MCP를 열면 화면 밖 호출이 생긴다 | 주 1,000회 |

**H1 채점 기준**: 전날 20:00 국내 마지막 가격 대비, 08:00 하이퍼리퀴드 가격(원화)과 08:00~08:10 국내 평균 가격이 같은 방향인지.
기간 2026-04-13 ~ 11-05, 종목별 139번 (±0.05% 안쪽은 제외). 정규장만 보던 이전 기준(15:30 → 09:00)은 넥스트레이드에서 이미 보이는 움직임까지 예측으로 쳐서 91%대로 부풀려졌기에 바꿈.
현대차는 거래가 적어 신호가 약함 → '신뢰 낮음' 표시 또는 노출 축소가 다음 결정.

## 3. 예측 계산법

1. 밤사이 차이 `g` = 지금 하이퍼리퀴드 가격(원화) ÷ 어제 20:00 국내 가격 − 1
2. 예상 움직임 `μ` = α + β·g (과거 개장에서 국내가 하이퍼리퀴드를 따라간 정도. β는 1 쪽으로 당겨 안정화)
3. 불확실성 `σ` = 과거 빗나간 폭(평일 밤 / 주말 따로) + 장 열리기까지 남은 시간만큼의 하이퍼리퀴드 변동성
4. 오를 확률 = Φ(μ/σ), 80% 구간 = μ ± 1.28σ. 그날 이전 데이터로만 계산해 채점 (walk-forward)

**예시 — SK하이닉스 11/4 아침**: 어제 20:00 1,414,000원 → 08:00 하이퍼리퀴드 +3.37% → 예상 +2.72% (약 1,452,500원), 오를 확률 약 98%, 80% 구간 1,427,700~1,477,200원 → **실제 1,451,776원(+2.67%), 방향·구간 모두 맞음**

## 4. 해결 방법 (프로토타입)

| 화면 | 답하는 질문 | 핵심 요소 |
|---|---|---|
| 홈 | "내일 아침 오를까요?" "지금 시세차익 기회 있어요?" | 종목별 오를 확률·예상 시작 가격, 비용 뺀 수익 |
| 종목 상세 | 두 시장이 어디서, 얼마나 벌어졌나 | 두 시장 겹친 차트, 호가, 주문(출시 예정 + 알림 신청), 예측 기록 |
| API · MCP | 에이전트가 같은 정보를 쓰려면? | 조회·주문 미리보기, MCP 도구 |

**시세차익 기회** = |가격 차이| − 주식 수수료·세금 − 하이퍼리퀴드 수수료 − 환전 비용 − 펀딩비. 공매도가 어려운 개인 기준으로 실행 불가한 방향은 표시.

## 5. 지표와 결정 규칙

- **North Star**: 개장 전(06~08시) 예측을 확인한 주간 사용자
- **첫 실험**: 종토방·주갤 4일 게시 → 첫 방문자 중 다음 개장 전 재방문 **≥ 15%면 개장 전 알림 개발**, 5~15%면 메시지 바꿔 재실험, 5% 미만이면 습관 가설 기각
- **가드레일**: 하이퍼리퀴드 방향 적중 4주 연속 75% 미만이면 예측 숨김. 레버리지 5배 이상 주문 비중 감시

## 6. 주요 결정

| 결정 | 이유 |
|---|---|
| 국내 시장 = 정규장 + 넥스트레이드 | 개인이 거래할 수 있는 시간 전체. 정말 닫힌 20:00~08:00만 예측 대상 |
| 환율은 업비트 원/USDC | 하이퍼리퀴드는 USDC 정산. 실제 돈이 옮겨가는 경로 |
| 단순 선형 모델 | 종목별 140번 남짓 표본 → 과적합 방지, 초보에게 설명 가능 |
| 주문은 '출시 예정' + 알림 신청 | 실수 주문 0건, 대신 수요(H4) 측정 |
| 해외 perp 거래 권유 안 함 | 국내 투자자 보호 대상이 아님. 조회와 판단까지만 |
